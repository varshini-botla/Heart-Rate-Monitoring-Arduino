# Real-Time Heart Rate Monitoring System Using Pulse Sensor and Arduino

## 📌 Project Overview
This project measures human heart rate (BPM) using the SEN-11574 Pulse Sensor and Arduino UNO. 
The system detects pulse signals, calculates Beats Per Minute (BPM), and visualizes data through Serial Monitor and Processing Visualizer.

## 🛠️ Components Used
- Arduino UNO
- SEN-11574 Pulse Sensor
- Connecting Wires
- Arduino IDE

## ⚙️ Features
- Real-time heart beat detection
- LED blinking synchronized with heartbeat
- BPM calculation
- Serial Plotter visualization
- Processing visualizer for live graph

## 🔌 Circuit Connections

| Arduino  | Pulse Sensor |
|----------|--------------|
| 5V       |     VCC      |
| GND      |     GND      |
| A0       |    Signal    |

## 🚀 How to Run
1. Install Arduino IDE
2. Install PulseSensor Playground Library
3. Upload the code to Arduino UNO
4. Open Serial Monitor (9600 baud)
5. Place finger on sensor to view BPM

## 📊 Output
- LED blinks on heartbeat
- BPM displayed in Serial Monitor
- Graph shown in Serial Plotter
